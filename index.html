Compositor

Personal short-form content automation workflow

Purpose

Compositor helps the account owner research content ideas, prepare short-form videos, manage a review queue and publish approved content to the owner's own TikTok account through authorised integrations.

How it works

The workflow may use TikTok Login and the TikTok Content Posting API so the account owner can authorise access, review prepared content, and upload or publish videos to their own account. Where TikTok requires declarations, privacy choices or content disclosures, those choices are supplied by the account owner before publishing.

Data use

Compositor requests only the permissions needed for the enabled workflow. TikTok data is used to provide the requested account and content-management features and is not sold.

Contact

For questions about this app, contact the owner through the project owner's GitHub profile.
